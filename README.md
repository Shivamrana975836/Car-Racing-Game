# 🏎️ Car Racing Game

A 2D car racing game developed using Python and Pygame.

## 🎮 Features

- Endless road racing
- Player car control
- Enemy cars
- Coin collection system
- Speed meter
- Fuel system
- Engine temperature system
- Explosion animation
- Night racing environment

## 🛠️ Technologies Used

- Python
- Pygame
